# Long artificial histories: replayable layout and deterministic feasibility

## Purpose and authorized scope

The score calculator is reviewed and built. Its conservative precision requirements need longer artificial histories than the failed short-history experiment used. Before registering or drawing a new experiment, prove that those histories can be retained and replayed on the operator's Windows PC. D41-D43 and the operator's current instruction authorize this bounded implementation after review.

This unit has no RNG, network, real-market input, broker access or sampled-study verdict. It does not modify the old generator, protocol, resource amendment, failed evidence, reserved streams or inference switch.

## Smallest implementation

Add a pure research module for the existing frozen finite innovation laws. A typed immutable evidence object contains a version, exact profile identifier, exact integer core span, and immutable binary payload. One byte per source date retains S,Q,G,epsilon1,epsilon2 and a two-bit jump-atom index. Bit 7 is forbidden; impossible jump atoms and dense gate-off atoms are refused. All source dates from -max(memory,1) through n-1+hold are retained, including the recognition-date halo and quiet dates. There are no halo entrants.

Validate the whole payload before replay. Refuse unknown version/profile, bool/noninteger or out-of-range span (2..1,048,576), mutable/nonbytes payload, missing/extra halo, unknown bits and impossible atoms. Encoding validates every field and refuses a wrong source origin or length. A SHA-256 identity binds the layout version, frozen law version, profile, core span and payload using an unambiguous canonical header. This identity is content integrity, not evidence authentication; source hashes and durable file claiming belong to a later sampled runner.

Replay every core date in chronological order using the existing formula and original entry count. Preserve strict-win rules and the exact invented cost and paired benchmark. Compute exact rational raw/win/excess aggregate totals with integer-scaled arithmetic and rolling holding-factor and volatility windows. Memory stays O(payload length), without expanded overlapping trade footprints. The whole retained source reconstructs each trade's deterministic ID, decision t-1, entry t, recognition/exit t+hold and original source footprint; aggregate output is not a substitute for the source.

The object can losslessly decode to the existing InnovationPath for short-span comparison. Long replay is separate from the old limited builder; do not relax or bypass its caps. Compare exact totals against the old completed-trade builder for every profile at legal spans and several deterministic paths, including jump extremes, varied signs, volatility, multiple trades, zero-entry sparse dates and ties. Test malformed evidence and replay endpoints. A deterministic long-size probe measures each proposed dense family, replays twice, verifies equality and writes a resource report outside experiment directories. It draws nothing and gives no coverage verdict.

## Measurement and decision boundaries

One-byte encoding reduces the illustrative confirmation core payload from14GiB to exactly7GiB (7,516,192,768 bytes). This still exceeds the existing3GiB cap before halos/metadata; it does not make the old confirmation eligible. A probe can conclude that a proposed route is blocked. Two replays establish determinism; comparisons with the old completed-trade builder establish independent parity.

Measure P1/P2/E+/E- at n=2048, P3=16384, P4=8192, P5/P6=32768 and P7=131072. Record per-family elapsed replay time, encoded bytes including halo, current available RAM/disk and process resident-memory snapshots (snapshots are not a hard peak cap). Project the sum to illustrative 512-development and 32768-confirmation histories. Separate measured payload size from projected metadata/output overhead and measured time from extrapolation. No new budget or repetition count is accepted by this probe. A separately reviewed, pre-draw protocol and supervised bounded runner remain necessary before any new sampled experiment.
