# Step 6a.2 Synthetic Calibration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Test the candidate CR2/Satterthwaite signal intervals against frozen, synthetic, known-answer cases; either select one provisional block/degree-of-freedom floor or leave inference disabled with a complete failure record.

**Architecture:** An offline script generates artificial trade vectors and paired artificial benchmark vectors. It evaluates the exact CR2 formula in batches for speed, with predeclared scalar-production and dense-oracle parity checks. A separate gate counts every generated, emitted, and refused replicate, applies simultaneous binomial uncertainty bounds, selects only the first calibration-passing floor, then tests that floor once on untouched validation streams. No calibration interval or floor is exposed by `SignalDiagnostics` in this step.

**Tech Stack:** Python 3.12, NumPy 2.1.3, pinned development-only SciPy 1.14.1 for Student-t and beta quantiles plus development-only psutil 6.1.1 for peak-RSS checks, pytest, Ruff, mypy, uv. SciPy is not a runtime dependency or imported by `icarus/`.

**Spec:** `docs/plans/2026-09-26-signal-statistics-design.md` §§3–5, 7–8; this plan freezes its previously open synthetic protocol. The numerical tolerances below are Icarus policy choices, not established statistical guarantees.

## Global constraints and pre-run freeze

- Commit this reviewed plan and a versioned machine-readable manifest before the first stochastic replicate. The manifest records its own SHA-256 in each result artifact; changing any field starts a new reviewed protocol and never overwrites a failed result.
- `goal.yaml` retains `signal_test.inference_enabled: false`. No real `Panel`, market prices, broker, lockbox, trial-ledger evaluation, official benchmark alpha, placebo p-value, promotion decision, or live order path is used. No SciPy import is added anywhere under `icarus/`.
- Keep the existing `H -> L=max(63,3H)` rule, full-source origin, one observation per filled trade, component-specific refusals, and unmodified `_cr2_moments` product behavior. This is not a real-market model.
- All 10,000 calibration and 20,000 validation replicates per cell are counted, including failures. Never regenerate a refused replicate or choose a more favorable seed. A validation failure ends the protocol; do not try the next floor.
- The research harness may use a batched exact formula, not an approximation. Any unexplained parity mismatch invalidates the entire phase's gate evidence.

## Frozen design and target construction

Enumerate cell IDs in the table order below, then increasing parameter order as printed. Anchor geometry is 24 occupied blocks with eight observations per block; default `H=21`, `L=63`, and fixed origin index 0. For an ordinary block with `n_g` entries, entry `j` (zero-based) is at source session `gL+floor((j+.5)L/n_g)`. Overlap entries split across the edge: for eight observations, offsets `(0,1,2,3,L-4,L-3,L-2,L-1)`; for ten validation observations, `(0,1,2,3,4,L-5,L-4,L-3,L-2,L-1)`. Thus late entries in block g share daily innovations with early entries in block g+1; a hold beginning at `s` uses daily innovation indices `s` through `s+H-1` inclusive. Burst entries share session `gL`, `gL+floor(L/2)`, or `gL+L-1` for first/middle/last. Entry coordinates are fixed before outcome generation in every cell; only holding duration and thus H/L/block grouping vary with the outcome in named dynamic-H cells. The base 35 anchor cells are mandatory for **every** candidate floor. Add seven support/edge cells described below, for 42 fixed-H coverage cells total, plus three dynamic-H cells, for 45 calibration coverage cells. Each cell has three separately judged metrics: raw `Y`, win `1[Y>0]`, and paired synthetic excess `Y-B`.

| Family (anchor cells) | Exact variants | Known target and dependence |
|---|---|---|
| Independent (5) | `p=.05,.20,.50,.80,.95` | Independent standard-normal latent sign draws. |
| Independent-block factor (6) | within-block latent `rho=.25,.75`, each at `p=.05,.50,.95` | `Z=sqrt(rho) F_g+sqrt(1-rho) eps_i`; independent `F_g`. |
| Same-session burst (3) | all eight entries in first/middle/last session of each block at `p=.05,.50,.95` respectively | `Z=sqrt(.75)F_day+sqrt(.25)eps_i`, where `F_day` is one independent standard normal per distinct absolute source session; no fold re-anchoring. |
| Unequal occupancy (3) | `p=.05,.50,.95` | Repeat block counts `(4,8,16,32)` six times; independent block factors with `rho=.25`. |
| Overlapping holds (6) | `H=21,42`, each at `p=.05,.50,.95` | Latent `Z=sum(daily_normal[s:s+H])/sqrt(H)` from one shared absolute-index daily-innovation array per replicate; there is no additional idiosyncratic term, so simultaneous/overlapping entries share shocks. Entries split between the first and last four/five sessions of each block, creating actual cross-block overlap. `L` is 63/126 respectively. |
| Cross-block serial factor (6) | stationary Gaussian block AR(1) `rho=.20,.50`, each at `p=.05,.50,.95` | Latent `Z=sqrt(.5) F_g+sqrt(.5) eps_i`; Draw `F_0~N(0,1)`; for `g>0`, `F_g=rho F_(g-1)+sqrt(1-rho^2) eta_g`. |
| Bounded rare magnitude (3) | `p=.05,.50,.95` | Block factor `rho=.25`; independent multiplier `A=20` with probability `.01`, else `A=1`. This has bounded support, not infinite-variance tails. |
| Two-regime shift (3) | regime-probability pairs `(.01,.09),(.20,.80),(.91,.99)` | First/last 12 blocks use the pair values; block factor `rho=.25`; target uses fixed observation-weighted regime means. |

For every cell, let `W_i=1[Z_i>Phi^-1(1-p_i)]`, `Y_i=.01 A_i(2W_i-1)`, and `B_i=.002+.005 F_i`. For ordinary cells, `A_i~Uniform(.5,1.5)` independently, so `E[A]=1` and raw outcomes are not an affine copy of wins. For rare-magnitude cells, `A_i=20` with probability `.01`, otherwise `1`, so `E[A]=1.19`. `F_i` is the same unit-variance block factor used in `Z_i` for block-factor, unequal, AR, rare-magnitude and regime cells; the same session factor for burst; the same normalized daily sum as `Z_i` for overlap; and a separate independent standard-normal block factor for independent cells. The exact targets are `E[Y]=.01 E[A] sum_i(2p_i-1)/N`, `P(Y>0)=sum_i p_i/N`, and `E[Y-B]=E[Y]-.002`. Benchmark and stock vectors are generated as a pair; their difference feeds the same CR2 kernel. The factors and amplitudes are drawn independently except where the same named `F_i` is intentionally shared by `Z_i` and `B_i`. These paired artificial values are **not** a benchmark-match certificate.

The seven additional fixed-H coverage cells are: independent `p=.50` with balanced `G=6,8,12,16`; AR(1) `rho=.50,p=.50,G=8`; unequal occupancy `p=.50,G=12` with `(4,8,16,32)` repeated three times; and overlapping `H=42,p=.50,G=16`. Three dynamic-H cells use `p=.05,.50,.95`, block-factor `rho=.25`, and ordinary entries spread over `24*126` source sessions with nominal `L=126`: each observation has `H_i=42` if `W_i=1`, otherwise `21`. Recompute observed maximum H, L, block membership, nu and cache key for each replicate; dynamic-H cells are always generated and a below-floor result counts as a refusal rather than disappearing. The anchor cells are never removed from a candidate's required matrix, and pre-run structural assertions require all 24-block anchors to satisfy every listed block and nu floor. For each candidate, decide eligibility from deterministic entry geometry and the occupancy-derived `nu` **before** outcome generation. Below-floor cells are required-refusal controls for that candidate, not that candidate's coverage denominators. Compute the **base estimator** interval/count vector once for every fixed cell before applying any floor; a candidate's deterministic eligibility mask only selects which base checks enter its pass decision. For an ineligible cell, assert 100% correct below-floor refusal separately, with no candidate-specific emission/coverage check. Dynamic-H cells must be proven by exhaustive two-H geometry calculation to have occupied blocks and nu above all four candidate floors in both phases; assert this before any stochastic draw, or invalidate the protocol rather than deduplicate candidate-dependent hypotheses. Also test a four-block fold, one occupied block among many empty time blocks, and a fixed-origin edge crossing as refusal/geometry controls; never shorten L or pool folds to make them eligible.

The **untouched validation matrix is not a reseeding of those same cells**. Give its cells numeric IDs 1001 onward in the following row/order: independent `p=.04,.50,.96` (3); independent-block `rho=.50` at those p (3); first/middle/last burst at those p respectively (3); unequal occupancy `(5,10,20,30)` repeated six times at those p (3); overlap `H=28,35` at those p (6); stationary AR(1) `rho=.30,.45` at those p (6); rare magnitude `A=15` with probability `.015`, otherwise 1, at those p (3); two-regime pairs `(.01,.07),(.25,.75),(.93,.99)` (3); and dynamic-H `H_i=35` for wins/28 for losses at those p on `24*105` source sessions (3). These 33 anchors use 24 blocks and ten observations/block, except unequal occupancy. Add four independent `p=.50` support cells with `G=7,9,13,17`, for **37 validation cells**. The same equations and exact analytic targets apply, with rare-magnitude `E[A]=1.21`. All validation parameter values and source geometry are frozen here, but **no validation-seed observation is generated** until the hashed first-passing calibration artifact is accepted. A candidate must retain at least one eligible cell in each family in each phase; all 24-block family anchors must be eligible for every candidate.

The ordered candidate `(minimum occupied blocks, minimum nu)` list is `(6,4), (8,6), (12,8), (16,12)`. These are search candidates, not accepted floors. The one selected pair must pass all eligible raw, win, and synthetic-excess cells in calibration and every eligible validation cell. A report-only CR1 comparator uses `V_CR1=G/(G-1)*sum_g(S_g^2)/N^2` and `t(G-1)`; it never selects or rescues a floor. No metric gets its own pair.

The required-refusal matrix contains: empty; one occupied block; below-block floor; below-`nu` floor; deterministic all-win/all-loss (raw may remain valid if returns differ); duplicated signal ID; invalid canonical axis/coordinate; non-finite, overflowing and underflowing Decimal; arithmetic invalid variance/df; and the existing missing-benchmark and indefensible-placebo refusals. Schema errors raise; valid degeneracies return typed reasons. The tested synthetic envelope is H in {21,28,35,42}; fixed-H G is 6–24 with 4–32 trades/block in calibration and 5–30 in validation; dynamic-H may regroup into more than 24 occupied blocks under its declared 24*126 or 24*105 session span. Sign probabilities are .01–.99, latent rho at most .75, and bounded A at most 20. Actual source coordinates and resulting block counts, not a claimed universal numeric envelope, define the tested designs. This is a **test envelope only**, not a product runtime guarantee or an added refusal for a valid future run. No latent serial or tail parameter is claimed detectable from one observed sample.

## Random streams, acceptance and parity

Use `numpy.random.PCG64` through `SeedSequence(master_seed, spawn_key=(cell_id, component_id, chunk_id))`, with immutable numeric cell IDs, component IDs and chunk size 256. Generate all arrays in a fixed call order and fixed shape per chunk; the final chunk draws only its declared remainder. No Python `hash()`. This avoids millions of per-replicate RNG constructions while keeping cells independent and replayable. Calibration master seed is `2026092602`, held-back validation seed `2026092603`; neither is the reporting-placebo seed `20260924`. `component_id` assignments are fixed in the manifest: 0=trade idiosyncratic normal, 1=block/session factor and AR innovations, 2=amplitude, 3=independent benchmark factor, 4=daily innovations. Each stream is drawn in ascending observation/source-index order; unused component streams are not drawn. Record NumPy and SciPy versions, estimator code commit, manifest hash, cell/replicate IDs, generation count, refusals, target, and exact acceptance calculation in append-only result artifacts. The validation command refuses unless the selection artifact verifies the manifest and code hashes, complete calibration counts, all acceptance results and the first-passing rule. The manifest uses canonical UTF-8 JSON (sorted keys, no insignificant whitespace); a detached SHA-256 file committed alongside it is the expected digest, verified against the clean Git commit before either phase. The harness and estimator must also be committed with a clean working tree; the artifact records their commit and tracked blob hashes. No validation-seed observation or parity probe may be generated before that gate passes. Process exactly 256 replicates per full chunk and a final remainder, and halt instead of silently changing design if a phase exceeds 2 hours or 2 GiB peak resident memory. Each phase writes one immutable JSON artifact under `docs/reviews/step6a2/` using exclusive create (`O_CREAT|O_EXCL`) and fsync; an incomplete artifact is an invalid attempt, never an accepted partial result. A failed code/parity/runtime attempt requires a newly reviewed attempt and commit; after any validation observation, new validation seeds and a reviewed protocol version are required before another attempt. Never overwrite an artifact.

Result artifacts use schema `step6a2-calibration-result-v1` and path `docs/reviews/step6a2/<protocol-sha-prefix>/<phase>-<attempt-id>.json`; `attempt-id` is the clean harness commit SHA plus phase name, so a second same-commit attempt cannot overwrite the first. Record protocol/manifest/harness/estimator hashes, Python/NumPy/SciPy versions, phase seed and cell definitions, each cell/metric target, R, emitted count, refusal histogram with sorted replicate IDs, lower/upper miss IDs, joint-success count, all five CP bounds and verdicts, report-only CR1 comparator summary, selected floor (if any), parity audit IDs/values, start/end UTC, elapsed seconds, and peak RSS. Store no market data and no per-replicate return vector; deterministic stream addresses and the event-ID lists make all counts reproducible. Measure peak RSS with a pinned development-only `psutil` dependency at each chunk boundary and immediately after the largest allocation; also calculate planned chunk-array bytes before allocation. Both 2GiB and 2-hour limits are hard incomplete-attempt cutoffs. Persist an invalid/incomplete artifact with its observed counts rather than accepting partial work. File creation is exclusive and fsynced; no resume, replacement or silent same-protocol retry.

For an emitted metric, compute the two-sided interval `mean +/- scipy.stats.t.ppf(.975, nu)*sqrt(V)`; preserve raw endpoints and clip only displayed win endpoints to `[0,1]`. Judge coverage and lower/upper misses against raw endpoints. A positive `nu` below a candidate floor receives a distinct `BELOW_CALIBRATED_DF` offline research refusal, not `INVALID_DF`; a low block count receives `BELOW_CALIBRATED_BLOCKS`. Component refusals do not erase another component's output.

For each candidate/cell/metric, require at least 95% emitted and at least 9,500/19,000 emitted in calibration/validation. On emitted replicates require simultaneous one-sided Clopper-Pearson lower coverage bound at least `.93`, and simultaneous upper bounds for **each** tail-miss probability at most `.04`. The emission fraction's simultaneous lower bound must also be at least `.95`. As a fifth check, count an emitted interval containing its target as success and every refusal or miss as failure among all generated replicates; require its simultaneous lower bound at least `.93`. This measures joint emission-and-coverage reliability, not unconditional CI coverage. Use Bonferroni family error `.05` separately per phase over **all unique predeclared cell x metric x five checks** in each phase, including fixed-H cells that a stricter candidate later refuses; these are base-estimator checks, not the candidate's emitted-coverage denominator. Identical anchor checks reused by four candidates are one hypothesis, not four. This is 45 x 3 x 5 = 675 unique base-estimator calibration checks and 37 x 3 x 5 = 555 unique validation checks; identical check vectors are counted once, while candidate-specific fixed-design refusal controls are outside the binomial family and must pass exactly; all counts are frozen before generating outcomes. An inconclusive bound is a failure, not a reason to add draws. These tolerances permit some departure from nominal 95% coverage; do not call them proof of exact coverage. No pooling of cells or metrics rescues a failure.

For every one-sided check use `alpha_adj=.05/M` with M=675 in calibration and 555 in validation. Define `CP_lower(k,n)=0` when k=0, otherwise `beta.ppf(alpha_adj,k,n-k+1)`; `CP_upper(k,n)=1` when k=n, otherwise `beta.ppf(1-alpha_adj,k+1,n-k)`. Equality at .93/.95/.04 passes. Conditional coverage and each tail use emitted n; emission and joint success use all generated R. Before any stochastic draw, use exact binomial CDFs (not a random pilot) to write the resulting integer pass-count cutoffs for R=10,000 and 20,000 into the committed manifest, and compute a Bonferroni union-bound lower estimate of whole-gate power for an ideal method with coverage .95, each tail .025, emission 1 and joint success .95. If that pre-run lower estimate is below .90, halt for reviewed redesign; do not generate data or loosen a cutoff after seeing outcomes. The unique-cell family correction covers floor selection because floors apply only a predeclared deterministic eligibility mask to identical base-estimator count vectors; any outcome-dependent floor filtering invalidates the stated family size.

The batch method implements `V=sum_g S_g^2/(1-n_g/N)/N^2` and occupancy-keyed `nu` exactly; the cache key is complete ordered `(block_id,n_g)` tuple plus `METHOD_VERSION`, never merely `G`. Before stochastic execution, check batch and scalar `_cr2_moments` against the existing independent dense oracle, hand cases, all-win/all-loss, equal block scores, concentrated counts, scaling, reordering and numeric boundaries. With the fixed eight outcomes `(0,0,1,1,2,2,3,3)`, four balanced blocks of two must have a narrower interval than the same observations regrouped into two occupied blocks of four (or the latter must refuse). For each cell and phase, the ordinary parity IDs are `floor(k*(R-1)/127)` for `k=0..127`, where R is the phase's frozen replicate count; this includes first and last. Additionally compare every non-finite/zero/near-zero result (near-zero means `0<V<=1e-12*S^2` or `0<sample_variance<=1e-12*S^2`, with `S=max_i abs(y_i)`) and every replicate with `abs(abs(t_stat)-t_critical)<=1e-8`. Match emission/refusal and coverage/tail decisions exactly. For mean and positive variance require `abs(a-b)<=1e-11*max(abs(a),abs(b))+1e-14*S`, where S is `max_i abs(y_i)` for mean and `(max_i abs(y_i))^2` for variance; positive dimensionless nu, design effect and effective N use relative `1e-11` plus absolute `1e-12`. Zero statuses must match exactly; no broad absolute tolerance permits tiny variances to appear equal. Any unexplained mismatch voids that phase; retain its artifact and review before rerun. Representative synthetic `SignalRunResult` tests separately prove source-axis, identity, Decimal-sign, H/L and edge handling, because the batch harness does not replace the public adapter.
